# consult_thread

## Purpose
One conversation between an acting pathologist and the consult agent about one case.

## Fields

| Field | Type | Null | Description |
| --- | --- | --- | --- |
| `id` | `uuid` PK | no | Generated by the database. |
| `case_id` | `text` FK | no | The case the conversation is about. |
| `user_id` | `text` FK | no | The acting pathologist. |
| `title` | `text` | yes | The first question, shortened. |
| `created_at` | `timestamptz` | no | |
| `updated_at` | `timestamptz` | no | Time of the latest message. |

## Relationships
- `case_id` → `path_case.id`, `user_id` → `pathologist.id`.
- Has many `consult_message`, deleted with the thread.

## Indexes
- `(case_id, user_id, updated_at desc)` — resume the most recent thread (F-07.1).

## Rules
1. Opening the consult panel returns the most recent thread for the case and acting pathologist, or creates one.
2. A thread is read only by its `user_id`.

## Source
Created when the consult panel is first opened for a case ([S-05](../screens/S05-consult-panel.md)).

## API shape
`ConsultThread` — `id`, `case_id`, `title`, `created_at`, `updated_at`, `messages` (list of `ConsultMessage`).
