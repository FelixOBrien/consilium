# annotation

## Purpose
A region or point a pathologist marked on a slide, with a label and note.

## Fields

| Field | Type | Null | Description |
| --- | --- | --- | --- |
| `id` | `uuid` PK | no | Generated by the database. |
| `slide_id` | `text` FK | no | |
| `case_id` | `text` FK | no | Copied from the slide. |
| `author_id` | `text` FK | no | The acting pathologist who created it. |
| `kind` | `text` | no | `rect` or `point`. |
| `geometry` | `jsonb` | no | Level-0 pixels. `rect`: `{x, y, width, height}`. `point`: `{x, y}`. |
| `label` | `text` | no | Short label, up to 80 characters. |
| `note` | `text` | yes | Free text. |
| `created_at` | `timestamptz` | no | |
| `updated_at` | `timestamptz` | no | Set on every change. |

## Relationships
- `slide_id` → `slide.id`, `case_id` → `path_case.id`, `author_id` → `pathologist.id`. Deleting a slide deletes its annotations.

## Indexes
- `(slide_id, created_at)` — list a slide's annotations.

## Rules
1. `geometry` matches `kind`, with integer values inside the slide's `width` and `height`, and positive `width` and `height` for a rectangle.
2. Only the author may change or delete an annotation (F-08.4). The API checks `X-User-Id` against `author_id`.
3. `author_id` and `slide_id` never change after creation.

## Source
Created and edited by users in the annotations panel ([S-06](../screens/S06-annotations-panel.md)).

## API shape
`Annotation` — all fields, with `author` as `PathologistRef` and `can_edit` computed for the acting pathologist.

`AnnotationCreate` — `kind`, `geometry`, `label`, `note`. `AnnotationUpdate` — any of `geometry`, `label`, `note`.
